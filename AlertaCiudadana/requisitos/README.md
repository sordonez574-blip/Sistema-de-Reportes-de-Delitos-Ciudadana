# Repositorio de Gestión de Requerimientos - AlertaCiudadana (Colombia)

Este directorio contiene la documentación viva, trazable y versionada de los requerimientos del sistema autónomo de gestión de incidentes urbanos **AlertaCiudadana**.

## Equipo de Desarrollo
- **Sergio Dario Ordoñez Aguilera** (Líder de Arquitectura y Trazabilidad)
- **Juan Camilo Perez Chivata** (Analista de Requerimientos y Validación)
- **Jonathan David Bohorquez Maldonado** (Desarrollador y Aseguramiento de Calidad)

## Estructura del Directorio
- `/funcionales/requisitos.md`: Especificación detallada de requerimientos funcionales (RF-01 a RF-05).
- `/no_funcionales/requisitos_nf.md`: Especificación de requerimientos no funcionales (RNF-01 a RNF-03).
- `/modelos/casos_de_uso.md`: Casos de uso asociados a las funcionalidades principales.
- `/cambios/cambios.md`: Registro formal de solicitudes de cambio (CR-01, CR-SEG-01).
- `/trazabilidad/trazabilidad.csv`: Matriz de trazabilidad bidireccional (Necesidad -> RF -> US -> CU -> Diseño -> Código -> Prueba).
- `/pruebas/pruebas.md`: Casos de prueba y criterios de aceptación (Given-When-Then).
